Icinga 2 AlmaLinux packages

Unofficial Icinga 2 rebuilds for AlmaLinux 9 and 10.

sudo curl -fsSL -o /etc/yum.repos.d/icinga2-alma.repo \
  https://digistatebv.github.io/icinga2-alma-builder/icinga2-alma.repo
sudo dnf install icinga2

Packages are not GPG-signed. The repo file uses $releasever, so AlmaLinux 9 and 10 pick the matching subdirectory automatically.
